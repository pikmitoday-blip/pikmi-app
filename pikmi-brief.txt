================================================================
PIKMI.TODAY — KOMPLETAN PRODUCT BRIEF
Platforma za freelancere: personalizovani portfolio linkovi + klijent tracking
================================================================

KRATKI OPIS
-----------
Pikmi je SaaS platforma za freelancere koja im omogućava da kreiraju
personalizovane portfolio linkove za svakog potencijalnog klijenta,
prate ko i kada gleda njihov profil, i šalju cold outreach poruke.
Umjesto jednog statičnog portfolia koji se šalje svima, svaki klijent
dobija poseban link koji freelancer može pratiti u realnom vremenu.

URL: pikmi.today
Tech stack: Next.js (App Router), Supabase, Stripe, Resend


================================================================
PLANOVI I CIJENE
================================================================

FREE PLAN
---------
- Pristup platformi s osnovnim funkcionalnostima
- Trial period (ograničen broj dana)
- Jedan uređaj po trial-u (zaštita od abuse putem device_id)
- Nakon isteka triala → prelaz na Pro ili gubitak pristupa

PRO PLAN
--------
- Puna funkcionalnost platforme
- Neograničen broj pitch linkova
- Outreach kit (šabloni za poruke)
- Email notifikacije o pregledima
- Stripe naplata (pretplata)
- Mogućnost otkazivanja u bilo kom trenutku
- Nakon otkazivanja: pristup do kraja plaćenog perioda
- Promjena načina plaćanja putem Stripe Checkout


================================================================
STRANICE I FUNKCIONALNOSTI
================================================================

1. LANDING PAGE (/)
-------------------
Javna marketing stranica:
- Hero sekcija s glavnom porukom: "Portfolio koji zatvara klijente dok spavaš"
- Features sekcija (kako funkcioniše)
- Pricing sekcija
- CTA dugmad: "Kreiraj profil besplatno" + "Login"
- Navigacija: Features / Kako funkcioniše / Cene


2. REGISTRACIJA (/register)
----------------------------
- Polja: Ime, Prezime, Email, Lozinka (min 6 karaktera)
- Anti-abuse zaštita: device_id provjera (1 trial po uređaju)
  → Ako isti uređaj pokuša drugi trial, prikazuje poruku s greškom
- Email verifikacija (Supabase auth)
- Greška ako je email već registrovan
- Nakon uspješne registracije → onboarding


3. LOGIN (/login)
-----------------
- Polja: Email, Lozinka
- "Zapamti me" checkbox:
  → Čekiran: čuva email + lozinku u localStorage (ključ: pikmi-remember)
  → Na povratku: automatski popunjava polja i čekira checkbox
  → Odčekiran: briše zapamćene podatke
- Greška: "Pogrešan email ili lozinka"
- "Zaboravili ste lozinku?" link
- Poruka ako je korisnik prijavljen na previše uređaja (max 3)
- Link na registraciju


4. ZABORAVLJENA LOZINKA (/forgot-password)
-------------------------------------------
- Unos emaila za reset lozinke
- Slanje reset linka putem Supabase emaila


5. ONBOARDING (/onboarding)
----------------------------
3-koračni wizard za nove korisnike:
- Korak 1 "Osnovno": Ime i prezime, Grad
- Korak 2 "Profesija": odabir zanimanja iz liste
  (Video editor, Copywriter, Grafički dizajner, Web dizajner,
   SMM menadžer, Fotograf, Drugo / kombinacija)
- Korak 3 "Tvoj URL": unos profil URL-a + provjera dostupnosti
- Progress bar s koracima
- Po završetku → redirect na dashboard


================================================================
DASHBOARD (/dashboard)
================================================================
Glavna stranica aplikacije nakon prijave.

STAT KARTICE (4 kartice):
- Ukupno linkova (ukupan broj kreiranih pitch linkova)
- Otvaranja (ukupan broj pregleda svih linkova)
- Hot lead-ovi (linkovi s 2+ pregleda — označeni vatrom 🔥)
- Aktivnih linkova (linkovi koji su trenutno uključeni)

TABELA PITCH LINKOVA:
- Kolone: Klijent (avatar + ime), Link (slug), Pregledi, Kreirano, Status
- Hot lead-ovi: istaknuti pink bojom s 🔥 ikonom
- Status badge: Aktivan (zeleni) / Neaktivan (sivi)
- Klik na link → otvara javni profil u novom tabu
- Prikaz "X dana/sati/minuta ago" za datum kreiranja

EMPTY STATE:
- Prikazuje se kad nema linkova
- CTA dugme za kreiranje prvog linka

QUICK ACTIONS (3 kartice):
- Kreiraj pitch link → /pitch-link
- Uredi profil → /profile-edit
- Outreach kit → /outreach

TEMA (dark/light toggle):
- Vidljivo samo na mobilnom uređaju
- Čuva se u localStorage (pikmi-theme)


================================================================
PITCH LINKOVI (/pitch-link)
================================================================
Kreiranje i upravljanje personalizovanim linkovima.

FORMA ZA KREIRANJE:
- Ime klijenta (naziv linka, obavezno)
- Slug / URL (pikmi.app/[slug], automatski lowercase, samo a-z 0-9 -)
- Personalizovana poruka (opciono, prikazuje se klijentu)
- Filter projekata (opciono, opis koje projekte prikazati)
- Dugme "Kreiraj pitch link" (onemogućeno dok polja nisu popunjena)
- Prikaz greške ako slug već postoji

LISTA KREIRANIH LINKOVA:
- Svaki link prikazuje: avatar (inicijal), naziv, pun URL, broj pregleda, status
- AKCIJE po linku:
  → "Kopiraj link" — kopira pun URL u clipboard (pokazuje "Kopirano!" 2 sekunde)
  → "Deaktiviraj" / "Aktiviraj" — uključuje/isključuje link
  → 🗑 Brisanje linka (bez potvrde)
- Status badge: Aktivan (zeleni) / Neaktivan (sivi)

PONAŠANJE LINKA:
- Aktivni link → prikazuje javni profil posjetiocu
- Neaktivni link → posjetilac ne može pristupiti profilu

ANALITIKA (/analytics)
================================================================
Statistike pregleda za sve pitch linkove.

FILTERI:
- Filter po linku: "Svi linkovi" + svaki link posebno (dugmad)
- Filter po vremenskom periodu:
  → 7 dana (dnevni prikaz)
  → 30 dana (dnevni prikaz)
  → 90 dana (sedmični prikaz — 13 sedmica)
  → Sve (mjesečni prikaz — 12 mjeseci)

STAT KARTICE:
- Ukupno pregleda (filtrirani period)
- Aktivni dani (broj dana s barem jednim pregledom)
- Mobile pregledi (📱)
- Desktop pregledi (🖥)

GRAFIKON (bar chart):
- Vizualni prikaz pregleda po periodu
- Ljubičaste bar-ove s gradientom
- Vrijednosti prikazane iznad bara
- Dinamički naslovi prema odabranom periodu

TABELA NEDAVNIH PREGLEDA:
- Maksimalno 100 redova
- Kolone: Pitch link (klikabilni link ↗), Uređaj, Izvor (referrer), Vreme
- "Direktan posjet" ako nema referrera
- Hostname iz referrer URL-a (npr. linkedin.com)
- Relativno vrijeme (Xm, Xh, Xd) + "ago"
- Empty state: "Nema pregleda za odabrani filter"

NAPLATA (/billing)
================================================================

PRIKAZ ZA FREE PLAN:
- "Free plan" status
- Informacija o trial periodu (ako je aktivan):
  → "Trial ističe za X dana"
  → "Trial istekao — nadogradi na Pro" (ako je istekao)
- Dugme "Pretplati se na Pro →" → Stripe Checkout
- Lista Pro benefita

PRIKAZ ZA PRO PLAN:
- "Pro plan" status + "✓ Aktivna" badge
- Detalji pretplate:
  → Sljedeća naplata (datum)
  → Iznos pretplate (EUR)
  → Kartica: brand + last4 + datum isteka
  → Posljednja faktura: iznos + datum + "Preuzmi PDF ↗" link
- Dugme "Promeni način plaćanja" → Stripe Checkout (setup mode)
  - Pamti loading state, reset na bfcache restore
- Dugme "Otkaži pretplatu" → modal za potvrdu

CANCEL MODAL:
- Poruka: zadržava se pristup do kraja perioda
- Dugmad: "Da, otkaži" + "Zadrži Pro"
- Nakon otkazivanja: prikazuje datum isteka s ⚠ ikonom

STRIPE INTEGRACIJA:
- Checkout: novi Stripe Checkout za pretplatu
- Setup mode: promjena kartice bez nove pretplate
- Webhook obrađuje: setup_intent.succeeded → auto-update default payment method
- Stripe API verzija: 2026-04-22.dahlia
- Kompatibilnost s novim API-jem (items-level period fields)

PORUKE:
- Success: "🎉 Uspešno! Tvoj Pro plan je aktiviran." (?success=1)
- Cancelled: "Plaćanje je otkazano..." (?cancelled=1)
- Payment updated: "✓ Način plaćanja je uspješno ažuriran." (?payment_updated=1)

JAVNI PROFIL (/[profileUrl])
================================================================
Stranica koju vidi potencijalni klijent kad otvori pitch link.

HEADER (sticky nav):
- Pikmi logo + link na homepage
- "Kreiraj tvoj profil" CTA dugme

LAYOUT:
- Identičan sa moj-profil izgledom (sidebar + main content)
- Potpuno statičan prikaz (bez edit opcija)
- Bijela pozadina, čist dizajn

TRACKING:
- Automatski se detektuje slug linka
- Server-side provjera da li je link aktivan
- Anti-self-view zaštita:
  → Ako je vlasnik ulogovan i gleda vlastiti link → NE broji se pregled
  → Provjerava se putem Supabase access tokena
- Bilježi: device (mobile/desktop), referrer, timestamp
- Povećava views counter u pitch_links tabeli
- Kreira zapis u link_views tabeli

EMAIL NOTIFIKACIJA:
- Šalje se odmah nakon brojanja pregleda (ne šalje za vlasnike)
- Putem Resend API-ja
- Email sadržaj: naziv linka, datum/vrijeme, uređaj, izvor, ukupno pregleda
- Dva CTA dugmeta: "Vidi analitiku →" i "Pogledaj pitch link ↗"
- Sender: konfigurabilan putem RESEND_FROM env varijable

KONTAKT MODAL (Zakaži poziv):
- Otvara se klikom na CTA dugme freelancera
- Polje za unos pošiljaočevog emaila
- Automatski detektuje provajdera:
  → Gmail: 3 opcije za različite naloge (u/{0,1,2}/)
  → Outlook / Hotmail / Live: direktni compose link
  → Yahoo Mail: direktni compose link
  → Ostali: mailto: fallback
- Subject: "Strategy poziv — [ime freelancera]"
- Recipient: automatski popunjen email freelancera

FALLBACK:
- Ako slug ne odgovara pitch linku → provjeri profile_url
- Ako ništa ne pronađe → "Profil nije pronađen" stranica

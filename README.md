# Pitchly

Moderni SaaS za personalizovane portfolio stranice i pitch linkove za freelancere i kreativce.

## Struktura
- `apps/web` — Frontend (Next.js, React)
- `apps/api` — Backend (Node.js/Express)
- `packages` — Deljeni kod, UI, utili
- `prisma` — Modeli baze i migracije

## MVP funkcionalnosti
- Onboarding sa profession picker-om
- Javni i personalizovani portfolio profil
- Editor profila (sadržaj, izgled)
- Pitch link creator
- Tracking dashboard
- Outreach kit
- Naplata (trial, pretplata)
- Auth: Google, Apple, Email
- Settings

Za detalje vidi PRD.
